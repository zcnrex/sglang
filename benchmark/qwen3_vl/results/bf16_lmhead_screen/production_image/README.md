# Production M4 LM-head image checks

All runs use the cached repository example_image.png fixture (SHA in request metadata), four concurrent image requests, greedy generation and 32 output tokens/request. Source manifests retain the reviewed three-file production overlay. No production edits were made by these probes.

The initial control/candidate probe produced identical token strings/content for all four requests, with actual candidate M4 capture and graph4 replay. Selected-token logprobs were not identical: maximum absolute differences 0.054489 for request 0 and 0.101319 for requests 1–3; 27–29 of 32 token records differed. These are cross-GPU/cross-scheduling results. Logs show different prefill grouping: control first processed one 234-token image then a 780-token mixed batch; candidate first processed a 78-token readiness request then 936 image tokens. Do not label those image probabilities numerically equivalent or attribute their differences solely to LM-head kernels. The strict logprob-equality comparison failed and is preserved.

A separate candidate-only causal diagnostic adds reference torch.mm on the identical actual hidden states and weight beside the optimized M4 operation during CUDA graph capture, retaining both output tensors. After graph4 replay it compares outputs outside capture, keeping the actual candidate output unchanged. All 24 observed M4 decode replay comparisons are bitwise identical (maxabs 0, normalized RMS 0, argmax identical). Four requests still generated 32 tokens each; their asynchronous arrival produced 24 common batch4 steps, with remaining steps on smaller batches. The arbitrary summary requirement of at least 25 steps failed although all 24 numerical comparisons passed. This is a coverage limitation, not a numerical mismatch.

This supports no LM-head numerical difference on those 24 checked image activations; it does not blanket-exclude every cause of the prior cross-batch probability differences. It is not a timing benchmark. Initial driver/server pairs 450117/450120 and450118/450119 completed; diagnostic 452629/452630 completed.
